# Lawn Mowing Simulator

A Windows game with a launcher: **Lawn Mowing Simulator** and the **Mining Simulator** (in development).

## Download
Get `LawnMowingSimulator.exe` from the [latest release](../../releases/latest). Windows may warn about an unknown publisher: choose **More info**, then **Run anyway**.

## Updates
The game checks for updates when it starts. If a new version is out you'll get a pop-up; **Download update** closes the game, replaces the old file and relaunches the new version. Your save is kept.
